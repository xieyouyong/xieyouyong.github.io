# 通量站点问答

查询缺少站点、变量或指定时段的数据时，页面保留原回复，并固定追加相关站点的 SITE_ID、站名、已发布数据的有效字段及各字段首末有效时间。部分变量或时段有数据时，仅对缺项涉及的站点追加信息。

`data/availability.json` 从已发布 DAT 和按年压缩的原始 CSV 统计生成。空值、非数值、-9999 和 -6999 视为缺测；0 是有效值。DAT 使用文件中的 UTC 时间，原始 CSV 按 `data/raw/index.json` 的站点时区换算为 UTC。首末有效时间之间可能存在缺测，不表示连续覆盖。原始 CSV 的有效字段包括观测、填补、质控和统计列。

更新 DAT、原始 CSV 或时区元信息后，在仓库根目录运行 `node flux/build-availability.cjs`，并将更新后的 `data/availability.json` 一起发布。构建不调用模型。

仅有站点目录、尚未发布观测文件的站点会说明无法核实有效覆盖，并显示目录来源供参考；不会把目录年份当成有效观测范围。
